# Digital Piano

A browser-based virtual musical instrument.

## Features

- Eight musical notes
- Mouse controls
- Keyboard controls

## How to Use

Select a piano key or use its corresponding keyboard shortcut.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Click each available key and check for audio output.
- [ ] Use the documented keyboard shortcuts.
- [ ] Check that repeated notes do not produce browser errors.
